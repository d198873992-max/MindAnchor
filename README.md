# MindAnchor（心智锚点）

> 基于大语言模型与图数据库的“个人记忆因果网络”构建系统。

## 🧠 项目背景与痛点
当前的大语言模型（如 DeepSeek）是无状态的，每次对话都像金鱼一样只有短暂记忆，无法构建连续的“自我意识”。
本项目（MindAnchor）旨在解决大模型在**“长期记忆锚定”**和**“情感因果演化”**上的底层逻辑断层。

## ⚙️ 核心理论
本项目基于“记忆锚点”社会学模型：人类的记忆不是静态数据，而是基于时间、情绪强度和因果关系的动态网络。
通过提取对话中的“实体”与“情绪极性”，在本地构建个人知识图谱（Graph）。让 AI 不仅记住你说了什么，更记住你为什么这么说。

## 🚀 技术架构
1. **信息输入**：通过 DeepSeek API（或本地 Llama3）接收文本。
2. **实体与因果提取**：通过 Prompt 强制模型输出 JSON 格式，提取 [人物, 事件, 情感评分, 因果链]。
3. **本地图网络 (NetworkX)**：构建节点（Event）与边（Causal Link）。
4. **权重衰减算法**：随着时间推移，普通记忆权重下降，但被标记为“高情感（痛/爽）”的记忆锚点，权重永久保留。

## 💻 快速开始 (Quick Start)
1. 安装依赖：
   `pip install openai networkx`
2. 配置你的 API Key：
   在 `main.py` 中填入你的 `DEEPSEEK_API_KEY`。
3. 运行主程序：
   `python main.py`
